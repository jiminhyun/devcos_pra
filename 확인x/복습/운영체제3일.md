# 프로세스
---
프로세스는 메모리에 적제된 프로그램을 뜻하며, 환경에 따라 포그라운드, 백그라운드, 데몬으로 나눌 수 있고 각각 사용자가 볼 수 있는 곳, 볼 수 없는 곳, 볼 수 없는 곳인데 사용자와 상호작용하지 않는 것->자동으로 생각하면 된다.로 나눌 수 있다.

# 프로세스 제어블록
---
pcb(프로세스 제어블록)에서 프로세스 실행 순서를 관리하고 자원 배분하는데 담긴 정보인  
레지스터 값  
프로세스 상태  
CPU 스케줄링 정보  
메모리 관리 정보  
사용한 파일과 입출력장치 목록
로 커널영역에서 관리한다.

# 문맥교환
---
문맥이란 하나의 프로세스 수행을 재개하기 위해 기억해야 할 정보이고
이를 바탕으로 pcb에서 백업, 복구를 하여 여러 프로세스를 빠르게 실행하지만 이를 너무 자주 발생시키면 오버헤드가 발생한다.

# 프로세스의 메모리 영역
---
프로세스 메모리 영역은 총 4가지 코드 영역, 데이터 영역, 힙 영역, 스택 영역으로 나뉘어져 있고  
코드: 보통 기계어 등들의 모임  
데이터: 보통 전역 변수 등들의 모임  
힙: 보통 객체같은 것등들의 모임, 프로그래머가 보통 직접 할당하여 쓴다.  
스택: 매개변수, 지역변수 등들의 모임  
정적 영역은 코드, 데이터
동적 영역은 힙 스택으로
한자풀이 그대로 정적은 변함x, 동적은 변함o이다.

# 스레드
---
스레드는 프로세스를 구성하는 실행단위로 하위 개념이다. 즉, 하나의 프로세스는 여러개의 스레드를 가질 수 있는 것이다.  
cpu가 실행하는 것이 바로 이 스레드이며, 이 스레드들이 각자 하나의 행동을 수행하고 여러개의 모여 프로세스를 이용하는 것으로 생각하면 된다.

# 멀티 프로세스와 멀티 스레드
---
멀티 프로세스랑 멀티스레드는 다중이라는 의미를 갖는다 생각하면 편하다.  
프로세스는 각자 자원을 점유하고 스레드는 하나의 프로세스를 상대로 점유되어있는 것을 나눠갖는 것이기 때문에
따로 vs 협력 이런 관점으로 둘을 구분하면 된다.
