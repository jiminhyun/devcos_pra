# 개요  

모든 프로세스 먼저 CPU를 사용하고 싶어하고, 이러한 프로세스들에게 공정하고 합리적으로 자원을 배분하는 것을 CPU스케줄링이라고 한다.  

# 프로세스 우선순위  

1. 입출력 집중 프로세스와 CPU 집중 프로세스
    - 프로세스마다 우선순위가 다른데 보통은 입출력 프로세스가 우선순위가 높다.  
    - (입출력, cpu)집중 프로세스는 말 그대로의 프로세스로 전자는 대기상태가 더 많고 후자는 실행상태가 더 많다.  
  
2. CPU 버스트와 I/O 버스트
    - cpu를 이용하는 작업을 cpu버스트, 입출력장치를 기다리는 작업을 입출력 버스트라고 한다.-> 이용과 대기로 구분한 이유는 cpu를 기준으로 보기 때문이다.  
    - pcb에 적힌 정렬된 우선순위를 바탕으로 프로세스가 우선 실행된다.  
  
3. 프로세스 우선순위
    - 보통 우선순위가 높은 프로세스는 입출력, 백그라운드, 실시간 처리 프로세스 등이 있다.  
    - 윈도우에서는 Process Explorer라는 소프트웨어를 통해 우선순위 확인 및 변경이 가능하다.
